Как добавить вина

Любой способ строит эталоны одинаково: YOLO-кроп этикетки → letterbox 518×518 → 116 аугментаций → векторы DINOv2 и SigLIP 2. Поэтому добавленное вино сразу распознаётся каскадом с теми же порогами «найдено» / «похоже» / «нет в каталоге».

1. Каталог CSV + папка фото (основной способ, уже загруженные вина пропускаются)

docker compose exec api python scripts/ingest_cascade_catalog.py --csv /imports/wines_integrated_cleared.csv --images-dir /media/catalog_sources

2. Пакет фото через API (POST /api/imports)

Положите фото и манифест в imports/staging/<batch_id>/. Манифест — CSV или JSON с колонками title, manufacturer, image_path и необязательными description, slug.

curl -X POST http://localhost:8030/api/imports -H "Content-Type: application/json" -d '{"batch_id": "batch1", "manifest_name": "manifest.csv"}'
curl http://localhost:8030/api/imports/<job_id>
