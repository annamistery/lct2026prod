Запуск прямого импорта

Импорт запускается на сервере внутри контейнера через консольную команду. Каждый товар проходит полную нарезку YOLO, расчет 384-мерного вектора DINOv2 на GPU и сохранение в базу.

Команда для полного импорта всех 1932 товаров в фоне:
docker compose exec -d api python3 scripts/import_from_csv.py
Команда для импорта первых 50 товаров для быстрой проверки:
docker compose exec api python3 scripts/import_from_csv.py --limit 50
